# NHP-fixation-analysis
This README explains the code used for statistical analysis of data associated with "Optimizing Fixation of Nonhuman Primate Testis for Integrated Histopathology and RNA-Based Molecular Pathology", Held et al 2026 (In Preparation). It is broken down into components describing the scripts used for statistical analysis of the 2 quantitative variables explored in the paper.  

## Hematoxylin-positive pixel analysis
The script Hematoxylin-Analysis.R takes data in the form of an excel spreadsheet containing average values between 0 and 1 corresponding to the percentage of hematoxylin-positive pixels in three 250 micrometer-squared areas in a given sample image. This value was obtained using a pixel classifier tool in QuPath trained as described in the Held et al 2026 paper Materials and Methods. The data are processed to ensure that all percentage values are stored as numeric variables and can be grouped according to fixation type, fixation time, and Animal ID. After processing, the data are assessed for normality and homoscedasticity using the Shapiro Wilkes (stats R package) and Levene tests (car R package) respectively. Since our data were not homoscedastic and consisted of integers bounded by 0 and 1, we moved forward with a beta regression analysis to assess statistical significance of the test conditions. Beta regression was performed using the betareg package in R, and model results were quantified and ranked using the Akaike information criterion (AIC, AICcmodavg R package). Finally, a scatterplot of the data with lines of best fit according to the optimal beta regression model was generated using the ggPlot2 R package.  

## Statistical analysis of the effects of different processing methods on RNA preservation and integrity
The script RNA-preservation-analysis.R takes data in the form of an excel spreadsheet containing the percentage of RNA fragments greater than 200 base pairs long (DV200) in RNA extractions from all samples at a short-term and long-term storage time. The spreadsheet houses the following variables: Animal_Number, Sample_ID, Fixative, Hours_Fixed, DV200, Date_Extracted, and Storage_Time. The data are processed to ensure that Date_Extracted is stored as a Date variable, Hours_Fixed is stored as a character variable, and both Hours_Fixed and Fixative variables are ordered so that the fixation times are leveled from lowest time to highest time and that PFA is considered the first variable and mDF the second. Additionally, a new variable, Hours_Fixed_numeric, is created to store fixation times as a numeric variable. The data are then subsetted into different dataframes depending on storage time (short-term storage dataframe, long-term storage dataframe, and combined dataframe). Beta regression analyses were run on each subsetted dataframe to determine the optimal fit model for each storage condition. Model results were quantified and ranked using AIC. Finally, a scatterplot of the data with lines of best fit according to the optimal beta regression model for the combined dataframe was generated.
